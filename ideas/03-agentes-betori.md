# 3. Sistema de agentes para una constructora (Betori)

Un sistema de agentes que **detecta, califica y da seguimiento** a cada oportunidad de estructura
metálica en México **antes que la competencia**, para que el taller de Betori nunca opere sin carga de
trabajo comprometida.

## Capacidades implícitas
- Detección de oportunidades (licitaciones, obra pública/privada, señales de mercado)
- Calificación / scoring de cada oportunidad
- Seguimiento hasta el cierre

## Métrica de éxito
Carga de trabajo comprometida del taller — cero huecos de producción.
